# 端到端加密消息服务端

---

## 1. 项目简介

- **语言**：Go 1.21 + SQLite
- **说明**：用于端到端加密聊天的消息中继服务器。
- **功能**：
  - REST API：注册、登录、联系人、离线消息、文件上传/下载
  - WebSocket 实时消息
  - 只存储和转发密文
  - TLS 自签名证书
  - token 认证和消息签名验证
  - 强制双向联系人

## 2. 构建方式

方式一：

```bash
bash build.sh
```

方式二：

```bash
cd src
go build -o ../build/msg_server .
```

生成产物：

```text
build/msg_server
```

## 3. 安全模型

- 服务端不接触明文。
- 文本和文件消息在客户端加密。
- 服务端存储：
  - 密文
  - 包装后的 AES 密钥
  - 加密文件名
  - 元数据（发送方、接收方、大小、时间）
- 没有接收方私钥，服务端无法解密内容。
